TN AGRIBOT - TAMIL NADU AGRICULTURE SCHEMES & GUIDELINES ASSISTANT
================================================================================

1. OVERVIEW
--------------------------------------------------------------------------------
TN AgriBOT is a Retrieval-Augmented Generation (RAG) assistant designed to help 
farmers, researchers, and officers navigate Tamil Nadu government agricultural 
schemes, subsidy allocations, and official department guidelines.

The system combines static/scraped web intelligence (TNAU Agritech Portal) with 
dynamic document ingestion (PDFs) to deliver grounded, cited answers using 
LangChain, OpenAI, ChromaDB, FastAPI, and Streamlit.


2. ARCHITECTURE & COMPONENTS
--------------------------------------------------------------------------------
- scrapper.py       : Asynchronous Playwright scraper extracting verified paddy 
                      and agriculture schemes from TNAU directly into 
                      `schemes_data.txt`.
- rag_service.py    : Core RAG pipeline utilizing LangChain, RecursiveCharacter-
                      TextSplitter, Chroma vector store, OpenAI Embeddings 
                      (text-embedding-3-small), ChatOpenAI (gpt-4o-mini), and 
                      LangSmith observability.
- main.py           : FastAPI REST backend exposing endpoints for uploading 
                      PDFs, triggering index rebuilds, resetting the database, 
                      and executing search queries.
- streamlit_app.py  : Streamlit web UI providing file upload management, live 
                      indexing metrics, and a conversational chat interface with 
                      grounded source citations.

4. PREREQUISITES
--------------------------------------------------------------------------------
- Python 3.10 or higher
- OpenAI API Key
- LangSmith Account & API Key (Optional, for request tracing)


5. INSTALLATION & SETUP
--------------------------------------------------------------------------------
1. Clone the repository and navigate into the project root:
   cd tn-agribot

2. Create and activate a Python virtual environment:
   python -m venv venv
   # Linux/macOS:
   source venv/bin/activate
   # Windows:
   venv\Scripts\activate

3. Install required packages:
   pip install -r requirements.txt

4. Install Playwright browser dependencies:
   playwright install chromium

5. Create a `.env` file in the root directory:
   OPENAI_API_KEY=your_openai_api_key_here
   
   # Optional LangSmith Observability:
   LANGCHAIN_TRACING_V2=true
   LANGCHAIN_API_KEY=your_langchain_api_key_here
   LANGCHAIN_PROJECT=tn-agribot


6. USAGE INSTRUCTIONS
--------------------------------------------------------------------------------
Step 1: Scrape Initial Scheme Data
   Run the web scraper to extract scheme details from the TNAU portal:
   python scrapper.py

   This will create or overwrite `schemes_data.txt`.

Step 2: Start the FastAPI Backend
   Launch the API server using Uvicorn on port 8000:
   uvicorn main:app --reload --port 8000

Step 3: Start the Streamlit Frontend
   In a separate terminal window (with the venv activated), launch Streamlit:
   streamlit run streamlit_app.py

Step 4: Interact with TN AgriBOT
   - Open your browser at http://localhost:8501.
   - Use the sidebar to upload relevant Tamil Nadu agricultural PDFs.
   - Click "Build / Replace Knowledge Base" to generate embeddings.
   - Submit farming, subsidy, or scheme queries via the main chat interface.


7. API SPECIFICATION (FASTAPI)
--------------------------------------------------------------------------------
- GET  /              : Healthcheck; verifies API availability.
- POST /upload_pdfs   : Accepts multipart form data (`files`) to save PDFs to disk.
- POST /build_index   : Chunks and embeds text from `schemes_data.txt` and PDFs.
- POST /reset_index   : Clears the Chroma vector store and removes uploaded PDFs.
- POST /ask           : Accepts `{"question": "string"}` and returns the grounded answer.
